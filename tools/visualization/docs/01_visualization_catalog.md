# 数学建模可视化分类与选型

## 范围与口径

“全部可视化种类”不存在一个可穷尽的封闭列表：领域论文会不断组合出新的图形。这里采用更可执行的口径，覆盖数学建模从数据审计、机理理解、模型验证、预测与优化到论文表达的完整工作流。目录当前登记 58 个稳定的图形原型；原型可以有不同外观，但不把同一语义的图因配色、方向或库不同而重复计数。

选图先回答三个问题，而不是先选库：

1. 要支持哪一个结论或决策？
2. 数据的结构是什么：表格、时序、矩阵、空间点、网络、网格、仿真轨迹还是调度区间？
3. 读者需要精确比较、看整体模式、理解不确定性，还是探索交互细节？

## 分类总表

| 类别 | 主要建模问题 | 应覆盖的图形原型 | 目录中的代表 ID |
|---|---|---|---|

## 数据结构到图形的快速路由

| 数据结构 | 第一选择 | 常用补充 | 需要警惕的误读 |
|---|---|---|---|
| 单变量或分组样本 | ECDF、直方图、箱线/提琴图 | Q-Q 图、原始点 | KDE 的带宽和直方图分箱会改变形状 |
| 二维连续变量 | 散点图 | 回归/平滑线、hexbin、二维密度 | 点重叠会掩盖样本密度 |
| 多变量表格 | 相关热力图、散点矩阵 | 平行坐标、小多图 | 相关不能解释因果 |
| 时间索引序列 | 折线与预测带 | 分解、ACF/PACF、控制图 | 不要把外推区间当作确定轨迹 |
| 空间点或行政区 | 点图、分级设色图 | 密度、等值线、OD 流 | 坐标系、面积尺度与分级方法会影响结论 |
| 图网络或流程 | 邻接矩阵、节点连线图 | 桑基图、中心性分布 | 复杂网络的“好看布局”不是统计证据 |
| 网格、函数或仿真场 | 等高线、热力图、向量场 | 表面、切片、动画 | 三维透视和色标范围可能制造假差异 |
| 优化日志或多目标解 | 收敛曲线、Pareto 前沿 | 可行域、参数敏感性 | 只展示单次随机运行会高估稳定性 |
| 任务与资源区间 | 甘特图、负荷图 | 排队/利用率曲线 | 不能只展示计划，需要对照容量或实际执行 |
| 分类/回归模型 | 预测-观测、残差、混淆矩阵 | ROC/PR、校准、学习曲线 | 高 AUC 不代表概率可用于决策 |

## 常见建模题型的最小图组

| 题型 | 建议至少包含 | 可按需要增加 |
|---|---|---|
| 回归或预测 | 样本分布/覆盖、预测-观测、残差、误差分布 | 特征归因、分组误差、预测区间 |
| 时间序列预测 | 原始序列与预测带、分解、残差 ACF | 情景扇形图、变点检测、滚动回测误差 |
| 评价与多指标决策 | 指标分布、方案对比表、排名稳定性 | 权重敏感性、平行坐标、Pareto 前沿 |
| 路径、选址和配送 | 点位/需求图、最终线路、成本构成 | 服务覆盖、OD 流、与基线的路线比较 |
| 调度与资源优化 | 甘特图、资源负荷、目标收敛 | 队长/等待时间、容量敏感性、关键路径 |
| 网络传播或关系分析 | 网络概览、中心性/度分布、社区 | 邻接矩阵、传播轨迹、干预方案比较 |
| 空间插值或风险评估 | 采样点与覆盖、等值线/栅格、误差空间分布 | 热点分析、交叉验证图、可达性分析 |
| 动力学或仿真 | 状态轨迹、相平面、关键参数扫描 | 分岔图、时空热力图、与观测数据对照 |

## 图形质量底线

1. 坐标轴必须有变量名和单位；时间序列必须说明时间粒度和时区。
2. 比较多个面板时优先共享尺度；不同色标范围会让不可比的数据看起来可比。
3. 所有误差条、区间和阴影带要写清楚是标准差、标准误、置信区间、预测区间还是分位数带。
4. 使用颜色时同时编码标签、线型、点形或直接注释，不能只让颜色承担语义。
5. 饼图只用于少量互斥且总和有意义的类别；高维雷达图和三维柱状图通常不适合精确比较。
6. 先展示原始数据或稳健摘要，再展示模型结果；不要让平滑曲线掩盖样本量和异常点。
7. 对随机算法、交叉验证和蒙特卡洛模拟，展示重复运行的分布、分位带或置信区间。

## 目录与分类的关系

命令行使用英文稳定 ID 和数据形态标签，便于脚本调用：

```powershell
mathmodel-viz recommend --stage optimize --shape multi-objective
mathmodel-viz list --category spatial --format json
```

完整的机器可读元数据只维护在 `src/mathmodel_viz/catalog.py`。本页用于解释和扩展分类，不复制一份可执行配置。
