# 问题二算法落地与实验说明

本文档对应 `code/t2/solve_q2.py` 的连续鲁棒选址模型，以及
`code/t2/enhanced_experiments.py` 的论文级数值验证入口。问题二没有独立的
观测样本表，因此“数据清洗”主要体现为输入参数校验、单位统一和几何域合法性
检查，而不是对观测记录做统计插补。

## 2. 输入检查与几何预处理

输入可以使用 `s1`/`svd_deg`，也可以使用 `detector`/`bearing_deg`。解析时检查：

1. 检测点、示向度和所有数值参数必须有限；
2. 接收半径满足 `0 < min_receive_radius <= max_receive_radius`；
3. 测向误差在 `(0, 90)` 度，权重参数满足 `0 < epsilon_w < 1`、`p_w >= 1`；
4. 圆边数、求积阶数和网格大小达到最小值；
5. 目标区域非空且具有正面积和正内切圆半径。

目标圆和第一检测点接收圆采用外接正多边形，再与测向误差楔形相交。外接近似
保留了保守性，但其边界不是原始圆的精确边界；因此结果应写为“给定
`circle_sides` 的保守数值参考解”。求积节点只用于近似连续积分，不应解释为把
目标位置离散成有限代表点。

## 3. 目标、约束与数值实现

`Question2Model` 对每个第二检测点 `P` 计算：

- 半无限接收约束残差 `H(P)`：对目标多边形和半径 `min_receive_radius` 的分段
  极值使用顶点、圆边界交点和方向支持点；
- 加权平均 DOP `J(P)`：将多边形三角剖分后使用 Gauss--Legendre/Duffy 求积；
- 共线奇异性：若 `S1-P` 直线穿过目标域，或某个求积节点的正弦低于
  `angle_sin_tolerance`，公共目标返回 `+inf`。优化器内部使用有限惩罚包装，避免
  SLSQP 的有限差分被无穷值破坏。

优化是数值搜索，不宣称解析全局最优。全局行先执行差分进化，再以 SLSQP 打磨；
局部行只执行相同预算的多初值 SLSQP。每个结果同时保存：
`strict_feasible`（`H <= 0`）、`feasible_with_tolerance`（`H` 不超过距离尺度
容差转换后的平方距离残差）、目标值、分支、迭代次数和函数评估次数。

## 4. 三类正式收敛表

### 4.1 `circle_sides`

对每一个圆边数重建目标多边形并重新优化。表中 `native_j_star` 是该边数和主求积
阶数下的结果，`j_at_reference_order` 用统一高阶求积重新评价同一个点，避免把
求积阶数变化误当成圆边数变化。应同时观察：

- 目标区域面积和内切圆半径是否趋于稳定；
- `j_star`、最优坐标和 `H(P)` 是否稳定；
- 外接近似是否仍是可接受的保守误差。

### 4.2 `quadrature_order`

固定最终圆边数，对每个求积阶数重新优化，而不是只在一个固定点上重算目标值。
`j_at_reference_order` 用最高阶重新评价，`relative_j_native_vs_last` 给出相对差。
只有当最优点和目标值都稳定时，才能把主结果称为“求积收敛”；单点复核只能称为
“积分评价稳定”。

### 4.3 候选网格分辨率

近优集合为 `J(P) <= (1 + tau) J*` 与接收可行域的交集。规则网格的单元中心分类
提供 `cell_center_area`，同时在节点场
`J(P) - (1 + tau)J*` 上用 `skimage.measure.find_contours` 提取连续折线。
只有所有折线闭合时才将鞋带公式面积汇总为 `marching_area`；若折线触及搜索框或
被不可行掩膜截断，则回退到单元中心面积，并在表中保留开放折线计数。

这里的面积是数值估计，不是连续候选区域的严格面积证明。等值线节点同时要求
`finite` 和 `reception_feasible`；不可行或共线节点被赋予正的水平集场值，避免在
接收域外绘制虚假候选边界。

## 5. 局部/全局搜索稳定性

`q2_search_comparison.csv` 对每个种子运行两种流程：

1. 局部：多初值 SLSQP；
2. 全局：差分进化探索后加入全局点，再执行同样的 SLSQP 局部打磨。

两种流程使用相同的 `max_local_starts`，并记录 `j_star`、坐标、分支、可行性、
成功次数和耗时。报告时使用“在给定随机种子和预算下的稳定性比较”，不要把差分
进化的一次返回值写成全局最优证明。若两个对称分支的目标值相差很小，应同时保留
两个点；分支跳变可能只是对称几何造成的等价解，而不代表参数敏感性很强。

## 6. Monte Carlo 定位误差与命中率

实验是对模型的独立验证场景，不是把随机分布加入主优化模型。每个种子执行：

1. 按三角形面积在 `Omega_1` 内均匀抽取目标点，并拒绝外接多边形中超出
   `max_receive_radius` 的极薄外溢部分；
2. 在 `[max(min_receive_radius, ||G-S1||), max_receive_radius]` 均匀抽取实际接收半径，
   因而第一检测点按题设已成功接收；
3. 在两个检测点分别加入独立的 `[-angle_error_deg, angle_error_deg]` 均匀测向误差；
4. 求两条无限测向线交点。方向行列式不超过 `1e-10` 时记为非有限交会；
5. 对主最优分支及其镜像分支分别记录结果。

指标分母必须明确：

- `second_reception_rate` 和 `joint_reception_rate` 的分母是全部试验次数；
- `finite_intersection_rate` 的分母是全部试验次数；
- RMSE、MAE、中位数和 P95 误差只在“第一、第二点都接收且交点有限”的样本上计算；
- 5/10/20/50 m 命中率的分母是全部试验次数，因此同时反映接收失败和近似平行造成的
  失败，不会把失败样本从命中率分母中删除。

结果文件为：

- `q2_monte_carlo_seed_summary.csv`：每个种子、每个分支一行；
- `q2_monte_carlo_aggregate.csv`：跨种子均值和标准差；
- `q2_monte_carlo_samples.csv`：复核用逐样本明细。

## 7. 敏感度分析的完整流程

先固定输入几何和数值预算，对文档规定的 `epsilon_w`、`p_w`、`tau` 网格逐组重新
优化。由于不同权重定义了不同目标函数，不能直接横向比较各组自身的 `J*`；应使用
统一参考权重 `J0(P*)` 重评各组位置。随后再做数值与假设敏感度：

1. `circle_sides`、`quadrature_order`、候选网格大小；
2. 局部/全局开关、随机种子、局部和全局预算；
3. `angle_error_deg`、接收半径上下界和 `feasibility_tolerance_m`；
4. `angle_sin_tolerance` 及不同目标位置分布；
5. 记录最优坐标、统一参考目标值、`H(P)`、严格/容差可行性、候选面积、连通分量、
   距离范围和两个分支。

敏感度图中若出现两个对称分支之间的跳变，应先对点关于首次示向度轴做镜像并比较
目标值，再判断是否是真实参数效应。候选面积的网格依赖必须在图表和正文中明确标注。

## 8. 论文中可采用的结论强度

推荐表述：

> 在外接多边形目标域、指定求积阶数、搜索预算和网格分辨率下，多初值局部搜索
> （并以差分进化作对照）得到数值最优参考点；候选区域由接收可行掩膜和
> `J(P)=(1+tau)J*` 的 marching-squares 数值水平集近似。

不应表述为：

- 已证明解析全局最优；
- 已得到精确连续候选区域面积；
- 单凭 DOP 数值已经证明真实定位误差最小。

Monte Carlo 结果可以支持“在给定随机误差场景下的定位表现比较”，但不能替代对主
数学模型的连续最优性证明。正式论文还应在图题或表注中注明圆外接近似、积分阶数、
搜索预算、随机种子和严格/容差可行判定。
