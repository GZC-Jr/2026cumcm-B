# 问题二敏感性分析（初步结果）

## 1. 场景与方法

- 第一检测点：圆心 `S₁=(0,0)`；首次示向度：`0°`；测角误差：`±1°`。
- 目标可行域：半径 1,500 米、中心角 2° 的扇形。由于第一点位于圆心，题设 1,800 米目标圆约束在本场景下不再起额外限制作用。
- 基准参数：`εw=0.30`、`pw=2.00`、`τ=0.05`。
- 单因素敏感性分析：
  - `εw`：在 `[0.10, 0.50]` 上等距进行 100 次试验，固定 `pw=2.00`；
  - `pw`：在 `[1.00, 3.00]` 上等距进行 100 次试验，固定 `εw=0.30`；
  - `τ`：在 `[0.01, 0.20]` 上等距进行 100 次试验，固定基准权重。
- 连续积分采用 Gauss–Legendre 求积；选址采用全局搜索加多初值局部优化；候选区域面积通过高密度极坐标网格近似。
- 由于场景关于 x 轴对称，最优点和候选区域均存在上下两个对称分支。

## 2. 基准结果

在 `εw=0.30、pw=2.00` 下，得到一组数值最优参考点：

- `P* ≈ (863.39, 504.54)` 米；对称点为 `(863.39, -504.54)` 米；
- `L* = 1,000.00` 米；
- `β* ≈ ±30.30°`；
- `J* ≈ 1,580.66` 米。

最优点稳定落在强接收约束边界 `L*=1,000 米` 上。

## 3. 初步结论

1. **εw 对最优位置影响较弱。** 当 `εw` 从 0.10 增至 0.50 时，最优偏转角仅增加约 `0.712°`，最优移动距离始终为 1,000 米。用统一基准权重重新评价时，`J₀` 的全范围相对波动约为 `0.00995%`。
2. **pw 对最优位置影响更弱。** 当 `pw` 从 1 增至 3 时，最优偏转角仅增加约 `0.438°`，最优移动距离仍保持 1,000 米；统一评价指标 `J₀` 的相对波动约为 `0.00198%`。
3. **τ 是候选区域最敏感的参数。** 当 `τ` 从 1% 增至 20% 时，候选区域面积由约 `2,778 平方米` 增至约 `177,113 平方米`，扩大约 `63.75 倍`。
4. **候选区域主要向内扩张。** τ 增大时，区域最大移动距离仍近似保持在 1,000 米，而最小移动距离由约 990 米下降至约 826 米。
5. **建模建议。** 权重参数可采用中间值 `εw=0.30、pw=2.00` 作为稳定基准；若希望兼顾可选空间与性能，建议重点比较 `τ=3%–10%`，而不是继续细调权重参数。

## 5. 数值解释边界

- 当前结果是连续模型的**数值近似结果**，不是解析闭式解。
- 候选区域面积与距离边界受网格分辨率影响；图表中约 998.61 米的最大距离应理解为趋近 1,000 米的网格近似。
- 当前采用单因素试验，尚未覆盖 `εw × pw` 的交互效应；若用于最终论文，可进一步加入二维响应面和积分/网格收敛性检验。
